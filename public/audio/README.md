# Audio assets

Folder ini disiapkan untuk berkas audio listening (mis. `market-day.mp3`).

Belum ada berkas audio yang disertakan. Halaman Listening Test akan menampilkan fallback yang jujur:
instruksi, transkrip, dan tombol "Mark as listened" yang tetap memungkinkan tes diselesaikan.
Untuk mengaktifkan pemutar, taruh berkas di folder ini lalu daftarkan di `src/data/listening.js`.
